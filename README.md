🐈 Desktop-Kitty

A tiny cat tied to a balloon, floating around... waiting to follow and chase you but beware because
it might insult you in a Shakespearean style if you click the mouse!


built with HTML, CSS, and JavaScript.

## Features

- 🐾 Follows your mouse cursor
- 🔄 Turns toward movement
- 🐱 Animated cat GIF
- 💬 Random meows
- 📜 Shakespearean insults

## Built With

- HTML
- CSS
- JavaScript

## How It Works

Desktop Kitty tracks mouse movement using JavaScript events and smoothly follows the cursor using requestAnimationFrame.

Click Kitty to interact with it:
- Odd clicks: Meow
- Even clicks: Shakespeare insult
